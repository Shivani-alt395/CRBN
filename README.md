# CBRN Defense Guide — MOPP Awareness

A responsive, informational single-page web application built to educate users on Chemical, Biological, Radiological, and Nuclear (CBRN) threats and the Mission Oriented Protective Posture (MOPP) framework used to respond to them.

**Live demo:** https://shivani-alt395.github.io/CRBN/

## What it covers

- **CBRN Threats** — a quick-reference breakdown of chemical (nerve & blister agents), biological (pathogens & toxins), radiological (RDD & fallout), and nuclear (IND & tactical) threat categories
- **MOPP Levels** — an interactive walkthrough of MOPP 0 through MOPP 4, showing the graduated response posture, gear configuration, and response time for each threat level
- **Equipment Reference** — an overview of indigenous protective systems (e.g. NBC suits, detection systems) relevant to the guide's context

## Built with

- HTML5, CSS3, JavaScript (ES6)
- Responsive layout, scroll-based navigation
- Deployed on GitHub Pages

## Why this project

Built to practice front-end fundamentals — semantic HTML structure, responsive CSS layout, and vanilla JS interactivity — while presenting real informational content in a clear, scannable format rather than a generic template layout.

## Run locally

Clone the repo and open `index.html` in a browser — no build step or dependencies required.
